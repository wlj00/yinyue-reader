## ✨ 功能特点

- **完全透明背景**：窗口背景 100% 透明，只有文字浮在桌面上，可叠加在任何窗口之上
- **始终置顶**：浮在工作界面（PS、浏览器、办公软件）上方，不挡操作
- **纯黑/纯白文字**：浅色背景用黑字、深色背景用白字，无描边更隐蔽
- **阅读进度百分比**：右下角实时显示当前读到哪（如 35%），随滚动条位置准确变化
- **章节跳转**：自动识别「第X章」，精确跳到任意章节（不再偏差）
- **多格式编码识别**：自动识别 UTF-8 / UTF-16 / GBK / GB2312，中文小说不乱码
- **中英文界面**：一键切换中 / English
- **黑白文字切换**：浅色背景用黑字，深色背景用白字
- **阅读进度记忆**：关闭后自动保存，下次打开自动回到上次读的地方
- **窗口位置 / 大小记忆**：记住你的摆放习惯
- **缓慢自动滚动**：空格键控制，浏览器式缓慢滚屏
- **鼠标滚轮翻页**：上下滚动即翻页，Ctrl+滚轮调字号
- **字号自由调节**：Ctrl + / Ctrl - 调整字体大小
- **全局快捷键**：`~` 随时隐藏 / 唤出
- **快捷键可自定义**：顶栏「键位」可改全部 10 项键盘快捷键（含全局热键），录制即用、保存立即生效、撞键拦截、带恢复默认；F1 被系统占用时也能换掉
- **流畅不卡顿**：打开大文件秒开，拖动窗口不闪不重影，切换顶栏瞬切
- **意见反馈**：顶栏「反馈」按钮弹出邮箱（1051783236@qq.com），一键复制
- **内嵌打赏码**：微信 + 支付宝收款码打包在程序里，二维码单独放大显示，手机直接可扫

## 🎮 快捷键

| 按键 | 功能 |
|------|------|
| `~`（Tab 上方的反引号） | 一键隐藏 / 显示整个窗口（全局） |
| `F1` | 显示 / 隐藏顶部工具栏（全局） |
| `空格` | 开始 / 停止自动滚动 |
| `↑` / `↓` | 上下翻页 |
| `PageUp` / `PageDown` | 整页翻页 |
| `Ctrl + / Ctrl -` | 字号增大 / 减小 |
| `Ctrl + T` | 章节列表跳转 |
| `Ctrl + 鼠标滚轮` | 字号增大 / 减小（鼠标操作，固定） |
| `鼠标滚轮` | 上下翻页（鼠标操作，固定） |
| `双击文字区` | 打开 TXT 文件（鼠标操作，固定） |

> 键盘快捷键**全部可以自定义**（10 项）；只有鼠标滚轮、Ctrl+滚轮、双击这三项鼠标操作保持固定。
> **按 F1 没反应？** Windows 把 F1 当作系统帮助键优先占用，属于常见情况。点顶栏「键位」，把「显示 / 隐藏顶栏」改成 `Ctrl+Shift+H` 这类带修饰键的组合即可。

## ⌨️ 自定义快捷键

点顶栏 **键位**，弹窗分成两页：

**全局热键（任何时候都生效）**

| 功能 | 默认键 |
|------|------|
| 隐藏 / 唤出窗口 | `~` |
| 显示 / 隐藏顶栏 | `F1` |

**窗口内快捷键（隐阅窗口有焦点时生效）**

| 功能 | 默认键 |
|------|------|
| 自动滚动开关 | `空格` |
| 上翻页 / 下翻页 | `↑` / `↓` |
| 整页上翻 / 整页下翻 | `PageUp` / `PageDown` |
| 字号增大 / 字号减小 | `Ctrl +` / `Ctrl -` |
| 章节列表 | `Ctrl + T` |

用法：

1. 点一下要改的输入框，然后**直接按下你想用的快捷键**（如 `Ctrl+Shift+H`、`Alt+Z`、`F8`、`Shift+↑`）
2. 点「保存并生效」——立刻生效，并自动记到配置文件里，下次打开还是这套键
3. 想回到出厂设置：点「恢复默认」，10 项全部还原成上表默认值

小提示：

- 任意两项不能设成同一个键，撞键会指出是哪两项并拒绝保存
- 全局热键如果已被别的软件占了，程序会提示注册失败，并自动退回原来的键位，不会把你锁在外面
- 配置存在程序同目录的 `reader_config.txt`，一行一项（`hideKey` / `barKey` / `scrollKey` / `upKey` / `downKey` / `pgUpKey` / `pgDnKey` / `zoomInKey` / `zoomOutKey` / `chapterKey`），手动改也一样生效
