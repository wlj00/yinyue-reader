# 隐阅 · 透明悬浮小说阅读器 (YinYue)

一款极简的**透明悬浮桌面小说阅读器**——文字直接浮在桌面上，工作摸鱼两不误。
无需安装，双击即用，绿色免安装，Windows 原生程序（.NET Framework 4.0）。

---

## ✨ 功能特点

- **完全透明背景**：窗口背景 100% 透明，只有文字浮在桌面上，可叠加在任何窗口之上
- **始终置顶**：浮在工作界面（PS、浏览器、办公软件）上方，不挡操作
- **纯黑/纯白文字**：浅色背景用黑字、深色背景用白字，无描边更隐蔽
- **阅读进度百分比**：右下角实时显示当前读到哪（如 35%），随滚动条位置准确变化
- **章节跳转**：自动识别「第X章」，精确跳到任意章节（不再偏差）
- **多格式编码识别**：自动识别 UTF-8 / UTF-16 / GBK / GB2312，中文小说不乱码
- **中英文界面**：一键切换中 / English
- **黑白文字切换**：浅色背景用黑字，深色背景用白字
- **阅读进度记忆**：关闭后自动保存，下次打开自动回到上次读的地方
- **窗口位置 / 大小记忆**：记住你的摆放习惯
- **缓慢自动滚动**：空格键控制，浏览器式缓慢滚屏
- **鼠标滚轮翻页**：上下滚动即翻页，Ctrl+滚轮调字号
- **字号自由调节**：Ctrl + / Ctrl - 调整字体大小
- **全局快捷键**：`~` 随时隐藏 / 唤出
- **流畅不卡顿**：打开大文件秒开，拖动窗口不闪不重影，F1 切换顶栏瞬切
- **意见反馈**：顶栏「反馈」按钮弹出邮箱（1051783236@qq.com），一键复制
- **内嵌打赏码**：微信 + 支付宝收款码打包在程序里，单文件即可分发

## 🎮 快捷键

| 按键 | 功能 |
|------|------|
| `~`（Tab 上方的反引号） | 一键隐藏 / 显示整个窗口（全局） |
| `F1` | 显示 / 隐藏顶部工具栏 |
| `空格` | 开始 / 停止自动滚动 |
| `↑` / `↓` | 上下翻页 |
| `PageUp` / `PageDown` | 整页翻页 |
| `Ctrl + / Ctrl -` | 字号增大 / 减小 |
| `Ctrl + 鼠标滚轮` | 字号增大 / 减小 |
| `Ctrl + T` | 章节列表跳转 |
| `鼠标滚轮` | 上下翻页 |
| `双击文字区` | 打开 TXT 文件 |

## 🖱️ 顶栏按钮

**打开 ｜ 中/EN ｜ ? 帮助 ｜ 黑白 ｜ 章节 ｜ 打赏 ｜ 反馈 ｜ 隐藏**

- **打开**：选择 TXT 小说文件
- **中/EN**：切换中英文界面
- **?**：查看帮助
- **黑白**：切换文字白 / 黑
- **章节**：弹出章节列表，双击精确跳转
- **打赏**：弹出微信 / 支付宝收款码
- **反馈**：弹出反馈邮箱（1051783236@qq.com），一键复制
- **隐藏**：隐藏窗口（用 `~` 唤出）

## 🖱️ 操作说明

- **移动窗口**：按住顶部灰条拖动
- **改大小**：拖窗口任意边缘 / 右下角小方块

## 📦 运行环境

- Windows 7 / 8 / 10 / 11
- 需要 .NET Framework 4.0+（Windows 10/11 自带，无需额外安装）

## 🚀 使用方法

1. 在 Releases 页面下载 `隐阅.exe`
2. 双击运行
3. 点「打开」选择你的 `.txt` 小说文件
4. 按 `F1` 隐藏工具栏，享受只有文字的悬浮阅读
5. 遇到问题点「反馈」，有收获点「打赏」
